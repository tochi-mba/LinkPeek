WHY LINKPEEK

Stay on the page. See everything behind it.

LinkPeek classifies the destination instead of blindly scraping every image. On supported forum threads it can collect media across the thread, prefer original uploads, and ignore avatars, emoji, icons, and duplicate quotes.

THREAD AWARE

Whole-thread media

Discourse-aware scanning fetches posts in batches and extracts actual posted media, not UI chrome.

ONE HAND

Touchpad native

Two-finger browse, horizontal scrub, pinch zoom, zoom-to-pointer, momentum filtering and edge resistance.

FAST

Preview first

Uses optimized previews while browsing, then original assets when you explicitly open or download them.

CUSTOM

Settings for everything

Hover timing, panel placement, gestures, media rules, caching, appearance, shortcuts and per-site overrides.

PRIVATE

Local by design

No account, no analytics and no LinkPeek server. The extension talks directly to the pages you ask it to preview.

LEARNABLE

Built-in tutorial

Interactive onboarding, touchpad calibration, contextual tips and a permanent ? controls sheet.

INSTALL

Install the CRX in Helium.

LinkPeek is distributed as a real .crx package. Chromium-family browsers reject a self-hosted CRX when you double-click or open the downloaded file directly. Install it from the browser extension manager instead.

Download LinkPeek.crxUse the button below. This is the packaged extension itself, not a source ZIP.
Open chrome://extensionsPaste chrome://extensions into Helium's address bar and turn on Developer mode.
Drag LinkPeek.crx onto that pageDrop the downloaded CRX anywhere on the Extensions page, then approve the install prompt. Do not double-click the CRX file.
