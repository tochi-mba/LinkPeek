HOW IT FEELS

Hover. Move in. Keep browsing.

The preview stays where it opened while you move from the link into it. Scroll vertically through media, use the grid for an overview, and pinch or double-click to inspect details.

READY

Prepared before hover

A bounded set of nearby thumbnails is warmed so likely previews feel immediate without downloading the whole page.

YOUR SPACE

Place it once

Drag the header, resize from any edge, and LinkPeek remembers the panel layout for future previews.

ONE HAND

Scroll-first controls

Scroll or use arrow controls to browse. Pinch zooms, horizontal movement scrubs, and the grid scrolls normally.

DEEP FALLBACK

Find media behind index pages

If a page is empty, an optional bounded search can inspect its linked pages while respecting depth, page, and gallery caps.

BOUNDED

Resource-aware

Shared request limits, thumbnail-first loading, decoded-memory budgets, cancellation, and Data saver keep work under control.

PRIVATE

Local by design

Preferences remain in browser storage. Preview requests go directly to destination sites and can be disabled per site.

INSTALL

Install LinkPeek in Helium.

Download the extension, then load it from the browser's extension manager. Browsers only install extensions straight from a click when they come from a web store, so a downloaded package is loaded this way.

Download and unzipMove the LinkPeek folder somewhere it can stay, such as Documents.
Open chrome://extensionsPaste the address into Helium (or Chrome, Edge, Brave) and turn on Developer mode.
Load unpackedChoose the LinkPeek folder. To update later, replace its contents and press reload; your settings stay.
Practice the controlsThe first-run guide lets you choose scroll direction and a loading preset.
