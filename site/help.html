INSTALLATION

Install LinkPeek

LinkPeek ships as a Chromium extension package (.crx). In Helium, do not double-click or open the downloaded CRX directly: Chromium can reject self-hosted packages that way with CRX_REQUIRED_PROOF_MISSING. Instead, download the CRX, open chrome://extensions, enable Developer mode, and drag the CRX onto that page.

Download the CRXUse the button below and leave the file as LinkPeek.crx.
Open Helium ExtensionsType chrome://extensions into the address bar.
Enable Developer modeTurn on the Developer mode switch on the Extensions page.
Drag and drop the fileDrag LinkPeek.crx from your Downloads folder onto the Extensions page and approve the prompt.
