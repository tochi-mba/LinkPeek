INSTALLATION

Install LinkPeek

LinkPeek ships as a Chromium extension package (.crx). Click Install on this site and open the package. Helium supports Chromium extensions. Some Chromium builds restrict extensions installed outside their store; if yours does, the browser will require its sideload/developer-mode flow.
